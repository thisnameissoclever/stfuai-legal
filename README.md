Legal pages for the STFUAI Podcasts app, served by GitHub Pages.

- `privacy/index.html` -> /privacy/
- `terms/index.html` -> /terms/

Plain HTML, no build step, no Jekyll. Edit the file and push; Pages redeploys.
The App Store listing and the app both link to these, so check them after any edit:
`AppConfig.PRIVACY_POLICY_URL` and `AppConfig.TERMS_OF_USE_URL` in the mobile repo.
